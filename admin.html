Subida masiva de productos

Pega un array JSON con tus productos. Útil para migrar catálogos antiguos o cargar muchos productos de una vez.

Formato esperado (cada objeto = un producto):
{"name":"Reloj X","description":"...","category_slug":"relojes-hombre","price_current":250000,"price_previous":null,"stock":3,"is_featured":false,"is_new":false,"is_offer":false,"is_limited_edition":false,"image":"https://... o data:image/jpeg;base64,..."}
· category_slug debe ser una subcategoría existente (ej. relojes-hombre, no relojes).
· image puede ser una URL pública o una imagen en base64 — ambas se guardan automáticamente.
